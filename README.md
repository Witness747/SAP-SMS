# Student Academic Planner and Student Management System (SAP-SMS)

## Overview

SAP-SMS is a full-stack web application designed to help students manage academic activities efficiently. The system allows students to organize tasks, track events, and manage academic schedules through a user-friendly interface.

The project demonstrates full-stack development concepts, REST API integration, database management, and the application of DSA concepts in academic management systems.

---

## Features

- Student task management
- Academic event management
- Create and view tasks
- View academic events
- Task priority and status tracking
- Due date management
- Backend API integration
- Database persistence

## API Modules

### Tasks

- GET `/tasks/`  
  Retrieve all tasks

- POST `/tasks/`  
  Create a new task


### Events

- GET `/events/`  
  Retrieve all events

- POST `/events/`  
  Create a new event
