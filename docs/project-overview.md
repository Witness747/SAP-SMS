# Student Academic Planner & Student Management System (SAP-SMS)

## Project Overview

Student Academic Planner & Student Management System (SAP-SMS) is a full-stack web application designed to help students organize academic activities, manage schedules, track learning programs, and improve productivity through structured planning.

The project originated from a personal challenge of balancing multiple academic and professional commitments across different platforms, institutions, and time zones. These include university coursework, internships, certification programs, self-learning activities, and personal development goals.

SAP-SMS aims to provide a centralized platform where students can manage their academic journey from a single dashboard instead of relying on scattered notebooks, calendars, reminders, and spreadsheets.

---

## Problem Statement

Students often participate in multiple learning programs simultaneously, including university courses, internships, certifications, workshops, and self-study programs.

Managing these commitments becomes difficult because:

* Events are spread across different platforms.
* Deadlines and schedules frequently overlap.
* Activities may operate in different time zones.
* Priorities are not always clear.
* Manual planning methods are difficult to maintain consistently.

As a result, students may miss deadlines, attend fewer sessions, experience scheduling conflicts, or develop a false perception of productivity.

SAP-SMS addresses these challenges by providing a structured planning and management system.

## Project Objectives

The main objectives of SAP-SMS are:

* Centralize academic and learning activities.
* Manage schedules and events efficiently.
* Track tasks, assignments, and deadlines.
* Improve prioritization and productivity.
* Reduce scheduling conflicts.
* Demonstrate practical application of Data Structures and Algorithms (DSA) within a real-world software project.

## Minimum Viable Product (MVP)

The first version of SAP-SMS will include:

### 1. Student Dashboard

* Overview of upcoming activities
* Pending tasks

### 2. Academic Planner

* Add courses
* Manage subjects
* Track assignments
* Monitor deadlines

### 3. Schedule Management

* Create events
* View weekly schedules
* Detect schedule conflicts
* Organize academic activities

### 4. Learning Program Tracker

* Track internships
* Track certification programs
* Monitor personal learning goals

### 5. Task Management

* Create tasks
* Set priorities
* Mark completion status
* Track progress

## Data Structures and Algorithms Integration

The project will demonstrate practical use of DSA concepts including:

* Arrays and Lists for storing collections of tasks and events.
* Hash Maps for fast retrieval of student and schedule data.
* Sorting Algorithms for organizing schedules and priorities.
* Binary Search for efficient event lookup.
* Stacks and Queues for workflow management.
* Priority Queues for task prioritization.
* Graph-based approaches for future recommendation and planning systems.
